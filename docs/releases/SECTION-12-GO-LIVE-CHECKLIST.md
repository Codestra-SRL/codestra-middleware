# Go-live checklist

- [ ] Release scope, version, risk, and customer impact approved
- [ ] Architecture, security, performance, regression, and isolation evidence attached
- [ ] Backup and isolated restore verified
- [ ] Rollback rehearsed and rollback authority available
- [ ] Disaster recovery evidence and RPO/RTO recorded
- [ ] Feature flags reviewed; production activation remains disabled until approval
- [ ] Maintenance window and customer communication approved
- [ ] Monitoring, alerts, dashboards, and operators ready
- [ ] Canary scope and stop thresholds documented
- [ ] Security, release, operations, and executive approvals recorded
- [ ] Production activation decision is separate and signed
- [ ] Post-deployment acceptance and post-implementation review scheduled
