# RevOps architecture

Server A (`65.109.65.169`) owns tenant-scoped leads, opportunities, campaigns, pipeline state, commissions, forecasting inputs, audit, and reconciliation. Server B (`5.9.108.250`) provides private advisory sales AI. Server C (`49.12.145.107`) provides marketing routes and health checks. Server D (`65.21.67.207`) provides narrowly scoped sales-call metadata.

Live publishing, dialing, automatic pricing, discounts, contracts, and commissions remain disabled.
