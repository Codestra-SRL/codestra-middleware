# Feature flags

The AI flags default to `false`: `AI_PLATFORM_ENABLED`, `AI_INFERENCE_ENABLED`, `AI_EXTERNAL_PROVIDER_ENABLED`, `LEAD_INTELLIGENCE_ENABLED`, `LEAD_DISCOVERY_ENABLED`, `LEAD_IMPORT_ENABLED`, `ODOO_AI_WRITES_ENABLED`, `VICIDIAL_AI_WRITES_ENABLED`, `POSTIZ_AI_WRITES_ENABLED`, `MAUTIC_AI_WRITES_ENABLED`, `AI_WORKFLOW_ACTIVATION_ENABLED`, `CALL_TRANSCRIPTION_ENABLED`, and `CALL_ANALYSIS_ENABLED`.

Lead import additionally requires the legacy `ODOO_LEAD_APPLY_ENABLED` switch. No UI action may bypass these gates.
