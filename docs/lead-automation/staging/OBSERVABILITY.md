# Observability, reconciliation, and kill switches

Collect isolated service health, Alembic head count, outbox depth, callback and
Odoo apply failures, HMAC rejection rate, nonce replay rejection, idempotency
conflicts, quarantine count, reconciliation gaps, n8n execution count, and lead
mutation count.

Block progression on any workflow activation, public route, non-staging
database host, lead mutation while default-off, communication attempt, Server B
route, or recording access. The primary kill switches are all Lead Automation
flags, result processing, Odoo apply, and the n8n binding; all remain false.
Audit records must exclude request bodies and secret values.
