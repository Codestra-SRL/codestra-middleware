# Lead intelligence

The score is 0–100 and retains components for intent quality, contactability, identity confidence, company fit, campaign fit, engagement, urgency, and source quality. Each component has a server-side ceiling. AI output is advisory, minimized, and must not replace deterministic DNC, consent, or identity rules.

Model/provider, version, input hash, components, latency, cost metadata, result, and correlation ID are intended audit fields. If AI is unavailable, deterministic rules continue and automatic contacting remains forbidden.
