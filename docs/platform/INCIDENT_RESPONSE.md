# Incident response

Kill switches default active for global social automation, provider dispatch, n8n social delivery, campaign automation and AI generation. Containment order: stop new intent, preserve canonical jobs and audit, prevent uncertain publish replay, isolate the affected account/workflow, notify operations, reconcile, then restore through an approved change.

`CdstSocialIncidentResponseV1` may notify and request a campaign pause; it cannot delete content or mutate provider state directly. Duplicate prevention, auth failures, unknown results, dead-letter spikes and security HIGH/CRITICAL findings create incident candidates.
